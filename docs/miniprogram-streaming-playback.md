# 公共音频缓冲播放与卡片修正（2026-10-16）

公共三首 Hero 的原曲、人声、伴奏在参考播放器中直接使用现有 HTTPS 音频地址，由原生播放器缓冲播放；不等待 `downloadFile` 将整段写入临时文件。仍经过资源租约，取消、页面隐藏、身份重置继续清理播放器状态；远程 URL 不执行文件删除。没有将 Token 放入 URL。

私人歌曲、Take、混音维持 Bearer 鉴权下载，因为现有原生播放器接口没有接入该请求头。录音开始前继续完整预加载伴奏，避免引入录音期间网络缓冲。以上两类不宣称已改为流式。

原有普通请求20秒、上传/下载60秒超时保持；远程播放器准备等待由15秒改为60秒，本地播放仍15秒。下载的超时会显示连接超时，其他平台失败统一为网络失败；本次移除了公共参考播放的下载环节，没有证明过去偶发下载错误的根因，也不承诺所有网络错误消失。

按需注入配置加入 app.config.ts，构建 app.json 已包含 `lazyCodeLoading: requiredComponents`，需在开发者工具重新运行质量检查确认。参考微信官方示例配置：https://github.com/wechat-miniprogram/weui-miniprogram/blob/master/src/app.json 。

本次样式授权仅作用于底部技巧卡片的 ×/‿，分别左移 .18em/.3em；└┘ 与歌词区保持不动。卡片恢复为原网页的内容范围，移除来源与复核及其置信度/证据说明，不删除后台证据数据。

验证：类型检查通过；音频/播放器11项、录音9项通过，其中新增公共播放不下载、远程租约撤销、不泄露私有URL及录音继续预加载的回归。Taro生产构建通过，Webpack21.19秒。真实手机首播速度、断网行为及标注位置仍需新预览复核；本轮仅客户端变更，无后端部署。
