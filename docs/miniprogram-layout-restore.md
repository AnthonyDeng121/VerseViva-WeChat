## 平台适配与功能入口

`miniprogram/src/ui/Shell.tsx` 提供原三分区头部；`Disclosure.tsx` 替代 HTML details/summary；`practiceLayout.ts` 保留 Vocal Part 选择顺序、次声部主句时间锚点、录音切区逻辑和原生触摸坐标适配。

歌曲选择使用微信文件选择器接回已有上传 API。缓存索引只保存在当前 origin/owner 命名空间，Hero 保持公共只读，缓存列表删除/重新分析仍通过后端授权。微信登录和隐私弹窗属于平台新增能力，不回退旧匿名浏览器身份。

录音原唱/伴奏选项通过 RecordingSelection 显式传给预加载服务，保持同一个 LocalPlayer 的互斥与同步证据。纯唱保存为 free_overdub、不发起分析。音轨名称编辑和重分析使用既有接口，不新增后端契约。

多轨拖动使用现有 `offsetFromDrag` 符号方向和微信布局查询；移动更新本地参数，结束持久化。原录音不改写，参数变化仍使旧合成失效。混音导出通过鉴权临时文件进入微信文件转存界面，不暴露音频 URL/Token，不伪装浏览器下载。
