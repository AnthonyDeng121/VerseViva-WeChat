# 录音准备与技巧区切换修复（2026-10-16）

用户报告准备伴奏长时间等待后取消、不能录制，以及录制时没有切换到技巧区，并要求移除录音区常驻的提交/AI处理说明。

## 对照与改动

原网页的录音流程也要求完整下载音频，但在歌曲载入后预取并保留 object URL。小程序此前点击开始录音才下载，且重录重复准备。现新增页内录音参考租约缓存：登录且歌曲载入后预取当前选择的伴奏/原唱；开始录音复用已有或正在进行的下载；重录只释放播放器借用租约，不重复下载。切歌、换号、退出页面清理主租约，原私有身份与到期边界保留。

小程序原准备流程设置原生 startTime 后，还在暂停状态调用 seek 并等待 onSeeked（5秒）。现移除此冗余步骤，使用 startTime 启动，保留 onPlay 实际起点校验和录音/参考实际启动门禁。部分设备是否因暂停跳转回调缺失而失败仍待真机证据；不将代码风险点写成已证实的手机根因。

修复已取消准备任务晚到后调用全局 stopReference、可能重置新一轮准备的竞态。运行层增加准备代次隔离，取消后的借用租约不载入播放器。

技巧区显示直接根据倒计时/启动/录制状态派生，不等待下一轮 effect 改 mode；进入倒计时后滚动至歌曲练习卡片，结束/错误继续回演唱。没有重排既有控件。

仅移除用户引用的 RecordingPanel 常驻说明。微信录音权限与隐私授权流程继续保留，隐私指引、后台数据流没有修改。
